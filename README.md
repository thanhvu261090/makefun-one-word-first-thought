One word, the first that comes to mind — the smell of rain on dry earth, arriving before you have a name for it.

> "petrichor"

## How it works

`main.py` holds the entry word as a constant, checks it against the kit's gate (UTF-8 text, 1–24 characters, not only whitespace, exactly one word of letters with no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
